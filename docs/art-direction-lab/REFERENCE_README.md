# SHIJI — V3 Poster Lab / V5 Spatial Poster 原始设计参考

**用途：** 供 Codex 的 Cover Studio 3.0 美术返工参考。均为独立交互视觉 Demo，不是实际 App 的业务代码。

## 重要：文件位置

此前这些参考文件保存在 ChatGPT 工作容器的 `/mnt/data/`，**不在用户本机 Downloads，也不在 GitHub 仓库**。必须先从 ChatGPT 下载压缩包，解压，再将 `docs/` 文件夹合并复制到本地 shiji 仓库根目录。

解压得到：

- `docs/shiji-v2/reference/v3-poster-lab/index.html` — V3 独立交互 Demo（原始单文件 HTML）
- `docs/shiji-v2/reference/v3-poster-lab/desktop.png` — V3 桌面截图
- `docs/shiji-v2/reference/v3-poster-lab/motion.mp4` — V3 动效预览
- `docs/shiji-v2/reference/v5-spatial-poster/index.html` — V5 独立交互 Demo（基于 V3 演化）
- `docs/shiji-v2/reference/v5-spatial-poster/desktop.png` — V5 桌面截图
- `docs/shiji-v2/reference/v5-spatial-poster/motion.mp4` — V5 空间动效预览

## 指令

以 V3 的海报美术与 V5 的空间交互为主要视觉基准，对 Cover Studio 2.0 当前封面生成引擎进行差距分析。先制作 12 张高质量、真实数据驱动、视觉构图有明显差异的封面设计板，供用户确认之后再集成；不能直接复制 Demo 的虚构素材或本地模拟存储进正式业务。原有大 Hero、数据库及同步系统不可改动。
