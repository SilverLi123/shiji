# V6 Smart Capture · 界面增量记录

## Overview

本次是 V5 Spatial Poster 的普通功能扩展。视觉权威仍为 [现有设计系统](../../desktop-app/DESIGN.md)，产品边界仍参考 [现有产品说明](../../desktop-app/PRODUCT.md)；本记录只描述实际新增的任务反馈，不替换 DESIGN.md、PRODUCT.md 或 `.impeccable/design.json`。

大幅 Hero、Spatial Deck、纯封面图库及 Studio／Calm、3D／Flat 保留。现有 SwiftUI 外壳与 WKWebView 管理区继续共用资源模型；新增入口位于侧栏“后台补全”，有活动任务时显示数量，点击展开既有管理对话框。主页不增加常驻任务卡片。

## Colors

任务面板复用画廊暗底、主要浅字、辅助灰字、荧光绿和珊瑚错误色。处理中／已完成使用荧光绿，失败使用珊瑚色；所有状态同时有中文文字，不单靠颜色表达。任务 CSS 直接引用现有 `--shiji-fg`、`--shiji-muted`、`--shiji-line`、`--shiji-lime` 与 `--poster-coral`，没有建立第二套主题。

独立收尾复核记录：任务辅助文字约（5.73:1）、错误文字约（7.30:1）、侧栏任务数量约（7.67:1）。`/tmp/shiji-v6-design-detector.json` 中继承的低对比告警不等同于本次任务文字的实测结果；这些数值也不代表整个产品已完成无障碍认证。

## Typography

沿用现有本地中英文字体栈。任务名称（17px／1.5）、状态与尝试信息（13px）、说明（1.65 行高）构成紧凑阅读层级；数量与尝试次数使用等宽数字。长名称、错误与建议允许任意位置换行，不截断恢复信息。

## Layout

沿用可滚动管理对话框（最大宽 620px、最大高 85vh）。概览与暂停操作横向排列，任务以细分隔线组织，每条上下留白（20px）；操作间隔（8px）并自动换行。视口不超过（520px）时，概览与任务标题／状态改为纵向排列。

每页最多 30 条，底部显示实际范围及总数，并提供“较新的任务／较早的任务”；边界按钮禁用。条目按任务创建顺序排列，补全状态变化不重排当前页。实测 1000 条任务能翻到 31–60；374px 手机网页的列表及底部分页无横向溢出。

## Elevation & Depth

任务层复用原有暗色管理弹层与背景遮罩，不增加空间舞台、卡片透视或新的动效控制器。V5 的深度与动效所有权保持既有约定；后台状态更新不触发成功飞入，保存反馈仍由真实收藏写入完成触发。

## Shapes

沿用管理对话框圆角、次要按钮和边界材料；任务列表使用平面分隔，不套多层卡片。面板按钮最小高度（44px），触控与键盘共用真实 button 控件。

## Components

- **快速收藏：** 先将收藏保存在本机，再后台解析标题、介绍和图片。失败保留原收藏与海报；本地保存成功不等于网络补全成功。
- **任务概览：** 显示待处理、处理中、待重试、已完成和失败数量。暂停切换为恢复操作，并说明正在读取的结果不会写入。
- **任务操作：** 始终提供“查看资源”；活动任务可取消，失败／已取消可重试。取消补全不删除收藏。错误保留可阅读原因与恢复动作。
- **整理建议：** 分类与标签显示为待确认建议，用户可接受或忽略。接受仅追加建议标签、填充未分类资源；已有整理不会被替换。
- **语义与焦点：** 入口声明打开 dialog，对话框由标题命名，概览使用 status，操作错误使用 alert，数量使用 polite live region。打开后聚焦首个操作；关闭返回入口。刷新保留可用操作焦点，暂停／恢复切换后焦点跟随新按钮；真实浏览器已用 Enter 验证双向切换。
- **轮询与草稿保护：** 页面可见时每 5 秒检查任务，隐藏时清除定时器、返回前台立即检查；同一时间只保留一个轮询请求，内容未变不重绘面板。后台结果需要刷新资源时，若对话框、详情或保存表单仍打开则暂缓，待安全时恢复；页面离开时销毁监听与定时器。

### 验证证据与限制

源码依据为 [任务脚本](../../desktop-app/static/capture-tasks.js)、[任务样式](../../desktop-app/static/capture-tasks.css)、[集成入口](../../desktop-app/static/app.js) 与 [页面语义](../../desktop-app/static/index.html)。浏览器实际验证了收藏、元数据补全、本地 PNG、建议接受、暂停期间保存、取消、重试、恢复及无效图片失败；最终回归为 245 个 Python 测试、53 个 Node 套件通过。测试通过不能替代平台交互实测。

## Do's and Don'ts

- 保留真实保存、后台补全与用户确认整理之间的状态区别；失败时让收藏、海报和恢复操作继续可用。
- 保留当前页顺序、键盘焦点、44px 按钮及可换行错误信息；任务结果不能覆盖打开的草稿。
- 不用任务功能改写 V5 视觉系统、纯封面浏览或 SwiftUI／WKWebView 平台边界。
- 不将继承告警写成新的设计规则。Impeccable 上下文指出的既存 DESIGN／sidecar 漂移保持原状，本次未获系统替换授权，不作顺带修复或规范化。
