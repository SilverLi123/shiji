# Cover Studio 3.0 art direction

The existing V5 renderer remains the presentation entry point. The editor adds Auto, five families and original V5. Recommendation scores use actual kind, title, description, exact host, category, language and tags; no resource-ID lottery, fabricated repository metrics or external AI API. An explicit saved style/layout wins. Explicit Regenerate advances a persisted seed within a family; refresh/remount never regenerates it.

| Family | A | B | C | Content emphasis |
|---|---|---|---|---|
| Editorial | headline/rule grid | tilted reading sheet over large glyph | offset color-separation frame | articles, Prompt, design references |
| Spatial | shaded orb/orbit | exploded engineering planes | isometric blocks | 3D assets, robotics, AI/model collections |
| Developer | actual monospaced code terminal | repository monogram/specimen | component/interface bars | source code, repositories, component tools |
| Kinetic | echoed skewed typography | crossing tension loops | outlined rhythm sequence | motion, dynamic type, audio |
| Minimal | aperture/photo caption | inset document | centered axis | real imagery, documents, quiet text references |

Variants change the visual subject and hierarchy, not just background color. Titles, code, source and technical labels come from actual fields; decorative geometry contains no invented metadata. The six named palettes and custom main hex use computed readable foregrounds; custom cover text remains separate from the original resource title.

Actual website/local images stay preferred in Auto. Explicit local/website/poster source, Fit/Fill and focal coordinates use the same saved policy as preview. Poster selection keeps existing attachment bytes. Decode failure reveals art and reports that state in the editor. Original V5 stays selectable inside this editor; no obsolete whole-product V2 switch is reintroduced.

`evidence/board-before.png` and `board-after.png` assemble screenshots of fifteen real page/card states through Store/API, not a replacement demo library. `art-manifest.json` records actual sample IDs and source fields. Editorial long-title budgets are tested at all three positions and densities; large/mobile companion captures show the affected Chinese text. Native SwiftUI adapts the same semantics using native text/geometry rather than embedding desktop HTML.
