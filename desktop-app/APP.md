# 拾集桌面 App 与浏览器采集助手

这是 macOS 本机使用版本：SwiftUI 原生窗口、系统 Liquid Glass 收藏浮层（macOS 26+），管理区复用现有资源库；macOS 14/15 使用系统普通材质。当前构建支持 Apple Silicon，依赖本机 Python 3.9+（这台 Mac 已具备）。没有新增第三方运行时依赖。

本目录是新增手机同步的候选版本。同步服务默认关闭；当前正式服务与资源库未被开发验收改动。iPhone 配套源码工程需要用户自己的 Apple Team、两个 target 相同 App Group；没有已签名 IPA 或真机验证。

## 开始使用

1. 如果当前还开着本轮临时验收 App，先按 ⌘Q 退出，再打开 `dist/Dev Resource Library.app`。可以把它拖入“应用程序”。正常双击启动会创建自己的独立资源库，使用 8782 端口；无需终端启动服务。
2. 点击 App 右下角拼图按钮“浏览器扩展”，再点击“显示扩展文件夹”。也可以解压 `dist/shiji-browser-extension.zip`。
3. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`；开启开发者模式，选择“加载已解压的扩展程序”，选取包含 manifest.json 的文件夹。
4. 在 App 配对面板复制配对码。打开扩展“连接 App”，填写 App 显示的本地地址（默认 `http://127.0.0.1:8782`），粘贴配对码，点击“保存并检查连接”。
5. 扩展显示“已连接”后，可以收藏网页与选中文字、保存当前可见区域截图，或右键收藏图片和链接。回到 App 后，收藏自动出现；打开编辑表单或其他面板时暂缓刷新，关闭后继续。

App 右下角的原生“收藏”入口展开为“收藏网址”和“添加素材”，按钮接入原有管理流程：附件预览、项目、标签、代码/提示词、筛选、回收站、撤销、备份恢复和后台封面补全。浏览器只在用户点击采集时读取当前页面，不自动扫描浏览历史。

## 手机与电脑同步

Mac 工具栏 **手机同步 → 开启同步**，选择当前 Wi-Fi 的私有 IPv4 地址，点击 **生成配对码**。iPhone 系统相机扫码打开拾集，或复制码到手机 **管理 → 电脑同步**；画廊左上角电脑图标也可进入。点 **配对这台电脑**，允许本地网络访问，再 **立即同步**。不要选择 `127.0.0.1`；配对码五分钟内有效、仅用一次，过期后复制按钮禁用。只有本机地址时，先连接 Wi-Fi，再停止并重新开启服务。

同步双向传资源、备注、标签、状态和本地附件。同一资源两边都改过或同网址对应不同 ID 时，在手机比较完整版本，选手机/电脑后 **同步所选版本**。手机 **App 前台自动同步**默认开启且可关闭；后台暂停，不使用云服务。Mac 需要保持运行并开启服务。IP、证书或资源库身份变更需要手机断开后重新配对。

面板按服务状态、连接/二维码、已配对手机、底部停止动作分组。手机错误集中显示在“需要处理”，冲突显示选择进度并优先处理；“已配对”不代表实时在线。

手机断开只清除手机凭据及检查点；Mac **停止同步**暂停监听并保留设备授权，**解除所有手机配对**撤销全部设备令牌。均保留收藏与附件。连接、冲突和排错细节见 [SYNC.md](SYNC.md)。浏览器扩展的配对码与地址仍用于本机采集，不能替代手机同步配对码。

## 数据与旧资源

新 App 默认创建独立空库：`~/Library/Application Support/DevResourceLibrary`，收藏与附件都保存在该目录，配对码也保存在本机。原网页库保持原状，没有自动搬迁。

要带入旧收藏：在原资源库导出完整 ZIP，在 App 侧栏“管理资源 → 备份与恢复”选择 ZIP，核对预检摘要，再确认恢复。JSON 不包含附件；带图片、音频或视频的库请使用完整 ZIP。SQLite schema 3 与 ZIP manifest 2 保持兼容。

关闭窗口后服务继续运行，扩展仍可采集；使用菜单“退出拾集”或 ⌘Q 才停止本地服务。下次打开 App 恢复原数据；启动遇到端口占用或另一实例持有同一库时拒绝连接到其他服务，并显示重试及日志入口。日志为数据目录内 desktop.log。

## 验证与边界

开发验收只使用临时库与 8783 端口；没有改动正式库或 8765 服务。后端测试覆盖采集认证、重复收藏、重启持久化、端口冲突和数据目录独占；前端测试覆盖采集报文、同步保护、有限形变与减少动态效果。App 原生搜索、收藏表单、采集内容与附件已经实际打开验证。

前一轮同步验收使用临时两端收藏库：Python 195 项（含 14 项同步）、生产 Swift URLSession 实际 HTTPS 双向编辑/附件、冲突、错误证书拒绝、迟到手机采集保护及原生核心/ZIP 互通通过。2026-10-08 微调的最终 Debug/未签名 Release、原生核心、模拟器 App Group/资产检查及 Mac 构建/签名验证通过，完整 Python 197 项通过，含原生 HTTP 模型、Vision 稠密二维码解码与 DNS 回归。此前监听超时由 faulthandler 定位为 `HTTPServer.server_bind` 对通配地址的反向 DNS 查询阻塞，最小 `TCPServer.server_bind` 覆写已避免查询；不是证书初始化或并发构建所致。

本轮已取得手机浅色画廊/详情、暗色配对和 Text Size 8 标题/滚动/空库，以及 Mac 关闭/二维码状态的原生截图。独立复审为“ship reviewed refinement”，仅批准已审查的微调范围；空库遮挡问题已通过补拍确认修复。Mac 画面是生产组件连接临时真实后端的隔离未激活窗口，不代表完整正式 App 操作链或激活态样式。冲突/错误完整操作、实体手机 Wi-Fi、相机扫码仍未验证；iPhone 系统 Share Extension 持续空白页仍未解决，不构成整产品批准。

浏览器安全策略禁止自动打开扩展管理页，因此扩展需要手动加载一次；尚未在本轮实际安装到 Chrome/Edge 后端到端点击验收。未发布到扩展商店，App 是本机开发构建，没有开发者证书公证。当前没有 Windows、Safari 浏览器扩展或云同步。手机局域网同步是独立的默认关闭 HTTPS 服务；现有桌面 UI 与浏览器 API 仍只监听本机回环地址。

## 重新构建

在候选项目目录运行 `python3 desktop/build.py`（需 Xcode/Swift SDK），输出 App、App ZIP 和扩展 ZIP。QA 环境可通过 SHIJI_DATA_DIR、SHIJI_PORT、SHIJI_PYTHON 指定临时库、端口和 Python。正常使用无需设置这些变量。
