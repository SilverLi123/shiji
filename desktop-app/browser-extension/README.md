# 拾集采集扩展

适用于 Chrome 和 Edge。首次配对需启动本地资源库，可靠采集需要 V6.1 或更新的电脑端。

1. 解压此扩展包。
2. 打开浏览器扩展管理（Chrome：chrome://extensions；Edge：edge://extensions），启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中含 manifest.json 的文件夹。
4. 在资源库的“浏览器采集”中点击“复制配对码”。
5. 点击扩展图标，展开“配对与设置”，填入资源库地址与配对码，保存。

点击“收藏当前页”保存网址、标题、页面描述和选中文字；点击“收藏并保存截图”额外保存当前可见页面截图。右键菜单可以保存页面、选中文字、链接与图片。

只在你点击采集时读取当前页；数据发往已配对的本机资源库，不会发往第三方收藏服务。浏览器内部页面不能采集。若来源图片被网站限制访问，可以用当前页截图或在资源库手动添加文件。

配对后，App 关闭时仍可收藏：扩展会先把当前网页内容和截图保存在浏览器，显示“等待发送”，而不是误报 App 已保存。打开 App 并保持浏览器运行后自动重试；也可以在“待发送”列表逐条重试。浏览器退出时不会发送，下次启动继续。重试发送的是首次保存的内容，不会重新截取已变化的页面。

每次采集有固定请求 ID。发送前核对电脑回执，保存成功但响应丢失时不会盲目追加内容。更改地址或配对码后，旧队列会暂停，需连接原资源库后重试；不会静默发送到另一台资源库。旧电脑端缺少回执功能时记录保留并提示升级。

待发送最多 100 条、合计 8 MiB；空间不足会明确告知这次未保存。可以移除待发送记录，App 中可能已经保存的收藏不会因此删除。卸载扩展会删除其本地待发送内容。配对码仅存于浏览器本机设置，不复制进每条任务；任务和回执不进入手机同步。

移动端或不支持扩展的浏览器仍可使用资源库中提供的“收藏小书签”，该入口要求本机应用运行。
