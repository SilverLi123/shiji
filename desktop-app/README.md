# 桌面 App + 浏览器扩展（当前候选版）

安装、配对、数据目录与验证边界见 [APP.md](APP.md)。以下是继承的网页版本历史文档，启动方式和自动备份说明以 APP.md 为准。

# 拾集 · 个人开发资源库

在本机收藏网站、截图、美术、音频、视频、代码片段和提示词。界面沿用 Solarized Light，无需账号或付费服务。

## 启动

macOS 双击 `启动资源库.command`，保留终端窗口。也可以在本目录运行：

```sh
python3 server.py
```

打开 http://127.0.0.1:8765/。需要 Python 3.9+，没有第三方 Python 依赖。端口占用可加 `--port 8766`，独立数据目录可加 `--data-dir /绝对路径`。关闭服务后再移动整个应用目录。

## 第一轮：采集和整理

- 粘贴网址自动读取标题、介绍、预览图与图标；手动填写的内容会保留。读取失败时可继续直接保存。
- 上传、拖入或粘贴截图；封面和附件保存到本机。用户上传的封面优先于自动网页预览。
- 多选资源，批量加标签、加入项目、标为已整理、移入回收站或恢复。标签管理支持重命名和合并。
- 同一资源可加入多个项目，并填写各项目独立的使用备注。编辑支持特殊名称（如 `__proto__`、`constructor`）；切换资源或新建时，各自备注独立加载，修改、清空和移出后的备注准确保留。
- 删除进入回收站，附件保留，支持恢复和通知撤销。
- 启动时和有修改后每分钟自动生成本机完整备份；也可随时下载或立即备份。

## 第二轮：素材和项目参考板

- “添加素材”或在主页直接拖文件先打开批量预览，支持图片、音频、视频和其他附件，单文件最多 64 MB；当前流程见第九轮。
- 图片可放大，音视频使用浏览器播放器，其他文件提供下载。具体播放能力取决于浏览器与文件编码；不能预览时显示恢复/下载说明。
- 每个附件都可记录作者、具体来源、授权与许可说明网址。免费资源的授权仍需逐个确认。
- 资源形式可选网站、本地素材、代码片段或提示词；片段支持语言说明和复制。
- 详情中的“收藏具体内容”可建立与来源网站关联的素材或片段。
- 项目参考板按网站、素材、代码和提示词组织资源，卡片展示这个项目的专属备注；也可切换卡片或列表。

## 第三轮：浏览器采集和检索

- “浏览器采集”中把“收藏到拾集”拖入书签栏，点击后打开预填网址、标题和选中文字的收藏表单。资源库需要运行。
- Chrome / Edge 采集扩展支持保存页面、选中文字、右键链接/图片、当前页截图。安装见下一节。
- 重复网址不重复创建；再次选中文字会追加到原备注，截图和图片会保存为附件。备注总长超过 10,000 字时会明确报错，可拆为独立片段。
- 关键词覆盖项目备注、附件名称/作者/来源以及片段内容；标签可组合筛选，超过 12 个标签时提供“所有标签”入口。
- “保存当前筛选”创建智能集合，保存关键词、项目、标签、形式、价格、授权、颜色、链接状态及常用/待整理等条件。
- 上传图片时提取主色；点色块或“按颜色找”查找颜色相近的截图/素材。
- “检查链接”检查当前列表或所选资源；403、访问受限或超时显示“暂时无法判断”，404/410 标为疑似失效。只在点击时检查。

## 第四轮：分层项目和批量网址

- 新建项目时可选择上级；侧栏箭头展开或收起下级，项目页显示路径。父级项目包含下级资源，同一资源在父级计数中只算一次。
- 在侧栏“项目集合”旁的管理按钮或项目页“项目设置”中重命名、移动和设置自动标签。项目名称全库唯一，最多十层，不能移入自己或自己的下级。重命名会同步资源关联、项目备注、下级项目和智能集合中的项目条件，包括回收站资源。
- 勾选“归档项目”会隐藏该项目和下级导航，收藏、备注和附件仍保留。可在“管理项目”中取消归档；下级受已归档上级影响时，先恢复上级，或把下级移到其他上级。
- 资源新加入项目时，会获得该项目及祖先的自动标签。普通编辑不会重新补回手动移除的标签；移动项目、调整规则或恢复资源也不会自动重标已有资源。需要补标时，勾选“同时应用到此项目及下级已有资源”，只为未删除资源追加标签。标签重命名或合并会同步资源、智能集合条件和项目自动标签规则。
- 点击“批量收藏网址”，每行粘贴一个 HTTP/HTTPS 网址或 `[名称](https://example.com/)`，一次最多 200 条。预览会标明无效网址、列表内重复、已收藏和回收站条目；只有新网址可选择导入，已有记录保持原样，回收站条目可前往恢复。
- 预览中可修改所选网址标题、选择统一项目和填写统一标签。收藏后进入“待整理”，并应用所选项目及祖先的自动标签；预览和导入不会逐个访问网页。提交时再次检查重复；输入错误时整批不写入。
- JSON 和完整 ZIP 保存项目层级、自动标签和归档状态。导入按项目名称合并：同名项目保留本库的现有设置，只补充尚不存在的项目；合并后层级无效时会拒绝导入。恢复不会额外应用自动标签，资源已有标签随备份内容处理。
- 数据库升级到 v3 时保留原资源；从 v2 升级前保存 `data/before-folders.sqlite3`，更早版本升级前保存 `data/before-upgrade.sqlite3`。

## 第五轮：附件去重与库检查

- 在侧栏打开“库检查”，点击“开始检查附件”。后台逐个读取已登记附件，核对 SHA-256 和大小，显示已检查数量；期间可切回资源继续收藏，也可点击“取消检查”。扫描只读，不修改附件、记录或来源说明；取消不会生成本次完整报告。
- “相同内容”只分组展示活动资源中有效且字节完全一致的附件。各副本仍保留独立记录、所属资源和来源/授权；点击“查看资源”核对用途及具体说明。跨资源不会自动合并或删除；库检查只核对完全相同的字节，视觉相近查找见第十一轮。
- “需要检查的文件”列出缺失、内容异常、无法读取、扫描期间变化或所属资源不存在的附件，回收站条目会标明“回收站”。回收站附件仍参与校验，但不计入相同内容分组。附件目录中的未登记文件也会报告，并保留在原处。
- 点击“查看资源”定位问题，或点击“从备份恢复”进入现有恢复面板。有效的完整 ZIP 可修复同一附件的缺失、损坏或符号链接位置；恢复先校验备份并保留恢复前快照，原有活动收藏的内容保持不变。修复后重新检查附件。JSON 备份不包含附件字节。
- 点击“下载检查报告”保存完整 JSON。页面最多显示 50 组相同内容、每组 100 个副本和 100 个问题附件，下载报告包含完整列表。
- 报告只保存在当前服务会话的内存中，重启服务后需要重新检查。资源/附件登记记录或本地文件状态变化会提示“请重新检查”；恢复缺失文件后同样需要重扫。库检查由点击触发，不是持续内容监控。重新检查或取消时可能仍显示上一次完成的报告，请核对检查时间。
- 同一资源再次上传相同字节和文件名，且作者、来源网址、授权、许可网址及颜色信息也相同，会复用有效已有附件。任一说明不同都会保留独立记录；跨资源上传仍各自保存。已有文件缺失或损坏时，重新上传会新建附件，不复用坏副本，也不会删除旧问题记录。

## 连续预览与显示密度（第六轮入口，第23轮扩展）

- 在有可预览内容的卡片点击“预览”，或聚焦封面/标题后按空格，从该资源首项开始；空格须不带修饰键且不长按重复，详情或对话框打开时不触发卡片快捷预览。“筛选与整理 → 连续预览”从当前结果首项开始；详情点击图片或音视频附件的“连续预览”从对应附件开始。
- 队列包括本地图片、音频、视频；没有本地图片时，保留已有网页缩略图或原有静态首页备用图。按当前完整筛选与排序、资源内附件顺序浏览，不受首批60条限制。队列在打开时固定，重开读取新结果；从当前结果之外或“库检查”打开详情只浏览所属资源，回收站单独浏览。无可预览内容时入口禁用。
- 音视频使用原生播放器，点击播放后才能开始，可暂停、拖动进度。无自动播放或模拟波形；倍速可选0.5/1/1.5/2，循环与倍速在本次打开期间保留，重开恢复1倍速、不循环。播放支持取决于浏览器和文件编码，没有自动转码。
- 点击“上一个/下一个”切换；播放器、输入框和选择框之外可用左右键、Home/End导航，播放器内保留原生媒体按键。首尾按钮按边界禁用。Esc或关闭按钮返回原触发控件；从详情打开预览后关闭，详情仍保持打开。切换和关闭停止并卸载旧播放器；关闭、编辑或替换详情也停止旧详情播放。
- 图片保留“适应窗口”“原始尺寸”和本地“找相似图片”；相似结果仍按原图片队列浏览。预览显示文件名、位置、所属资源、尺寸/时长/大小、作者、来源与许可。“查看资源”定位所属资源，“下载原文件”用于本地图片、音频和视频，网页缩略图不提供原文件下载。
- 缺失、损坏或浏览器无法解码时显示恢复说明；失败音视频隐藏播放区域、提示、倍速和循环，保留切换、关闭、来源、下载及资源入口，下一项有效媒体恢复正常。缺失文件可从有效完整备份修复。预览不改资源、附件或备份格式，本轮未新增后端或数据schema。
- 在显示密度中选择“舒适密度”（默认）或“紧凑密度”。当前灵感板两种密度均保留三/二/一列的大图布局，列表等视图沿用较紧凑的信息排列，参考板保留分组。切换密度或视图会保留筛选条件与批量选择。
- 密度偏好由当前浏览器的 localStorage 保存，刷新后仍生效；它不写入收藏数据库、JSON 或完整 ZIP 备份，换浏览器时需重新选择。

## 第七轮：浏览器书签 HTML 导入

- 在浏览器导出书签 HTML 后，点击侧栏“导入浏览器书签”上传。支持标准 UTF-8 Netscape 格式，一次最多 5 MB、2000 条书签；无效 UTF-8 会提示重新导出。Chrome、Edge、Safari、Firefox 常用此格式；本轮验收使用标准格式测试文件，未逐个实测各浏览器当前版本的真实导出。
- 默认勾选“保留原文件夹结构”，新根项目名称默认为“浏览器书签”，可修改。每次建立新项目，根和文件夹遇到全库同名项目时加数字后缀，预览显示实际保存路径；不复用已有项目。取消保留后，所有所选书签放入新根项目。
- 点击“预览书签”查看新网址、已收藏、回收站、文件内重复及无效条目。仅新的 HTTP/HTTPS 网址可导入，已有收藏和回收站内容保持原样；回收站条目可使用原恢复入口。每页 100 条，跨页保留选择、修改的标题与统一添加标签；“选择全部新网址（跨页）”作用于全部页。未选择条目的空名称不阻止导入。
- 文件内同一网址只导入第一条，合并不同文件夹归属、去重标签及不同书签 DD 描述。书签描述保存为纯文本备注，文件夹 DD 描述不导入收藏备注。第一条书签的有效 ADD_DATE 保留为原收藏时间；缺失或无效时使用导入时间，无效值会提示。不会推断来源授权。
- 标题最多 200 字，描述最多 10,000 字，标签每个最多 50 字、最多 30 个；源字段截短或无效时间会在预览明确提示，重复项合并标签/描述超限也提示。书签标签和统一标签合计超过 30 个时需减少后再导入；所选标题需有效。
- 保留结构时，原文件夹最多九层，加新根最多十层；每资源最多 30 个项目归属。超限条目会提示返回取消保留文件夹。只创建所选新资源所需的文件夹和祖先路径，不导入空文件夹。源文件夹名超过 200 字会要求先缩短重新导出；新项目名称按现有 80 字限制整理，实际名称见预览。
- 点击“导入所选书签”后进入“待整理”。提交会重新解析原文并核对原文、选项及当前网址/项目状态的预览令牌；收藏或项目变化时需返回重做预览。只校验所选条目，整批在一个事务中写入，失败时资源和新项目一起回退。
- 预览和导入只解析文件文本，不执行 HTML/脚本、不访问书签网页、不获取图标。原“批量收藏网址”仍可用于粘贴网址或 Markdown 链接。

## 第八轮：可编辑智能集合与高级筛选

- 点击“高级筛选”调整当前条件，点击“应用筛选”只改变当前范围内的显示结果。取消或关闭不提交；回收站仍只筛选回收站，不能保存为活动智能集合。
- “保存当前筛选”打开同一表单，可修改集合名称和全部条件；新建与编辑的预览范围是整个活动库。常用收藏、待整理、素材附件、代码与提示词范围会带入相应条件。有效条件显示匹配数量、范围和前五个资源名称；无效条件显示调整提示。预览在本地匹配，不访问资源网页。
- 在集合页点击“编辑已保存条件”，修改名称和规则后“保存集合修改”保留原集合 ID；已不存在的集合会报错，不会重新创建。“另存为新集合”建立新 ID，原集合保留。名称最多 80 字。
- 在集合页调整搜索、标签或其他筛选会提示“当前筛选已修改，尚未保存到集合”。“恢复集合条件”恢复已保存规则；“当前条件另存为集合”保存当前条件。编辑始终从已保存规则开始，不会自动吸收临时修改。
- 表单先显示关键词、包含/排除标签、项目、形式、价格与授权；“更多条件”提供分类、链接状态、域名、日期、整理状态、附件与颜色。不同条件同时满足。包含标签默认“全部标签”，可改为“任一标签”；命中任一个排除标签即排除。
- 域名只填写主机名称，例如 `reactbits.dev`，不要填写协议、路径、端口或通配符。默认包含子域，可取消以仅匹配这个主机；只检查资源自身网址，不检查资源或附件的来源网址，不查询 DNS。兼容的 Unicode 国际域名可直接填写；`ß`、final sigma、joiner 等转换会改变名称的输入会被拒绝，此时填写浏览器地址栏对应的 ASCII 域名（`xn--…`）后重新预览。
- 收藏日期按 UTC 判断，包含起止两天，可只填一侧；开始晚于结束会报错。“没有标签”“没有项目”检查资源归属；“有使用备注”包含资源备注和项目专属备注。
- “本地附件类型”按附件 MIME 匹配图片、音频、视频或其他文件，网页缩略图不算附件。“素材资源或有本地附件”匹配本地素材形式或带本地附件的资源；“代码片段或提示词”匹配对应两种形式。这两项仅在勾选时约束，取消表示不限。“常用收藏”和“待整理”的“不限/是/否”中，“否”也是有效条件。
- 原有条件保留：关键词需包含全部空格分隔词，覆盖资源、项目备注、片段和附件说明；项目包含下级；形式、分类、价格、授权、链接状态按对应值匹配；颜色沿用相近颜色匹配。旧集合缺少新增字段时保持原匹配语义，打开表单不会改写已保存规则。
- JSON 和完整 ZIP 保存全部新增条件。完整 ZIP 恢复保留集合 ID；JSON 导入沿用按名称合并并生成新 ID 的规则。标签重命名或合并同步包含/排除标签，项目重命名同步项目条件。

## 第九轮：批量素材预览与可靠导入

- 点击“添加素材”，使用“选择文件”或“选择文件夹”，也可把实际文件拖入主页。每批最多 200 个文件、合计 2 GB，每个文件须为 1 字节至 64 MB。空文件及超限项会提示原因。预览和取消均不保存收藏或附件。
- 预览每页 20 条，可逐条改名、勾选或取消选择，翻页保留这些修改及统一整理信息。“只选新文件”和“取消全部选择”作用于全部页；只校验所选条目的名称，未选择项的空名称不阻止导入。

## 第十轮：大库备份与附件修复

- 在“备份与恢复”点击“下载完整备份”或“立即本地备份”。制作期间制作、下载和导入按钮暂时禁用，面板显示等待及结果；下载准备完成后由浏览器接管传输。历史备份仍可从下方记录下载。

## 数据和备份

- 收藏：`data/library.sqlite3`；附件：`data/files/`；自动备份：`data/backups/`。清除浏览器缓存不会删除这些数据。
- 完整 ZIP 包含 manifest.json、SQLite 快照、附件、项目、智能集合和回收站。导入以 manifest 和附件为准，SQLite 是额外恢复快照，不直接覆盖当前数据库。
- 完整备份恢复采用合并：同网址的现有收藏保留，回收站条目和附件根据备份恢复；不会把新修改替换成旧版本。附件按哈希校验，并拒绝无效路径或损坏文件。
- 恢复前自动生成紧急快照，保留原 SQLite 与可读取的损坏字节；可导入 manifest 排除缺失/损坏附件与封面引用，并在 missingFiles/damagedFiles 中记录问题。符号链接不会被读取。快照无法补回本就缺失的字节；普通完整备份遇到缺失、损坏或无法安全读取的源文件会明确失败，请先运行库检查或用有效备份修复。
- JSON 只交换条目、项目与智能集合，不包含附件字节；要备份素材请使用完整 ZIP。JSON 最多 12 MB。完整 ZIP 压缩后及展开后的内容各限 16 GiB，单个附件和 manifest 各限 64 MiB（面板简写为 GB / MB）。资源最多 10,000 条、附件 20,000 个、项目及智能集合各 1,000 个；制作备份与恢复采用相同数量限制，普通和紧急快照均先检查，超限会提示分库整理后重试。
- 自动备份不自动清理历史，历史会持续占用空间；制作与恢复也需要临时磁盘空间。素材多时定期将备份转存到其他磁盘，并管理本机磁盘空间。
- 旧数据库会自动迁移，升级快照位置见第四轮说明。恢复另一台机器的完整 ZIP 后，扩展需使用那台机器的配对码。

## 网络边界

服务仅监听 127.0.0.1。网页读取限制公开地址、大小、重定向和整体超时。部分代理的 DNS 会把公开网址解析为内网地址，此时服务器自动读取、远程图片缓存和链接检查会回退到手动填写/暂时无法判断；可以上传截图，或用扩展读取已打开页面的基本信息。

当前是单机个人工具，没有跨设备云同步、外部 AI、团队账户、自动转码或网站完整离线镜像。
