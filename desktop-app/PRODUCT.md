# Product

## Platform

macOS 本机桌面 App + Chrome / Edge Manifest V3 浏览器扩展；管理工作区由 WKWebView 承载，保留本地网页界面。当前 App 为 Apple Silicon 构建，最低 macOS 14；macOS 26 使用原生 Liquid Glass，macOS 14/15 使用系统普通材质。运行依赖本机 Python 3.9+，没有新增第三方运行时依赖。

## Users

个人开发者与创作者，在浏览网页时保存网站、选中文字、图片、链接和截图，回到 App 用图像、分类、标签、项目与备注寻找和管理参考素材。

## Product Purpose

把“看到值得保留的内容”连接到“本机资源库中可找回、可使用的素材”。先快速收藏，再按项目和用途整理；名称、来源、授权与附件保持可追溯，数据能够完整导出。

## Capabilities and Constraints

### 浏览器采集与 App 联动

Chrome / Edge 扩展由用户手动加载一次。App 右下角扩展入口显示文件夹、真实本地地址与配对码；扩展保存地址与配对码并检查连接。配对码加载期间禁用复制，失败显示重试，不提前显示“已复制”。默认服务地址为 `http://127.0.0.1:8782`，临时 QA 使用8783；设置地址必须与当前 App 一致。

扩展支持主动收藏当前网页及选中文字、右键收藏图片或链接、保存当前可见区域截图。只在用户发起采集时访问相应页面，不持续扫描浏览历史。API 使用本地配对认证与来源检查。重复网址安全合并采集内容，选中文字与当前备注在同一事务合并；保留其他并发编辑字段。重复采集回收站资源时恢复原记录，不替换其原名称。

App 自动读取新增收藏；详情、编辑、对话框、正在保存或页面在后台时暂缓更新，避免覆盖草稿。关闭面板后恢复同步。原生搜索与右下角“收藏网址 / 添加素材”接入原有受保护动作，不维护第二套资源模型。附件上传使用系统文件选择器，下载使用系统保存面板；外部 HTTP(S) 来源在浏览器打开。

### 浏览、整理与素材管理

清晰的大图灵感板是默认浏览面，480px以上两列、以下一列；列表与按资源形式分组的参考板保留。搜索、分类、项目、常用、待整理、回收站、排序、标签、颜色与组合筛选可共同定位资源。“筛选 / 显示 / 选择”使用独立可关闭面板和可移除条件，Esc / 外部点击返回焦点。舒适与紧凑密度、构图与完整图片显示选择保存在当前浏览器，不写入资源或备份。

每次先展示60条匹配资源，“继续浏览”每次追加60条；参考板按形式分组各追加。总数、搜索、全选和连续预览仍依据完整匹配范围。按资源ID更新卡片并保留可用焦点，分类数量统计整个活动资源库。

收藏支持网站、图片/音频/视频等附件、代码、提示词、名称与说明、作者、准确数组标签、价格及许可记录。真实封面优先；已有特定网站的静态首页备用图仅作为固定时点预览，不注册为用户附件、不改写授权或价格。来源与授权集中显示，未知信息明确记为待确认；详情只有一个主要“编辑”按钮。

项目支持最多十层层级、父级聚合、自动标签、移动和可恢复归档。单条与批量加入项目、移出项目和加标签使用可搜索选择器；批量写入同一事务。标签输入每次确认完整名称，逗号保留在名称内。移出项目保留项目使用备注，重新加入可恢复原备注；详情可原位明确保存或取消备注草稿，同段并发冲突保留草稿供比较。编辑保护保留来源、授权、其他字段与附件，不用采集刷新覆盖未保存输入。

批量网址或 Markdown 链接导入支持预览；浏览器书签 HTML 支持上传、预览和选择新网址。拖放、粘贴截图与文件导入使用既有附件流程。批量移入回收站提供15秒撤销，20条以上先确认；智能集合删除可撤销，恢复资源保留附件和元数据。

本地连续预览支持图片、音频、视频和已有网页预览，音视频使用浏览器原生播放器，手动播放；失败保留切换、关闭、下载和查看资源的恢复路径。相似图片查找仅在本地实际图片上临时比较颜色与结构，不使用AI、语义识别或外部图像索引。库检查由用户手动启动，校验SHA-256/大小、标出缺失或损坏并报告重复内容；检查只读，文件复用是另一个明确动作，保留独立附件记录、来源与许可。

网站封面补全默认关闭，开启后后台逐项处理，至少间隔30秒；读取og:image，失败时可用独立配置的本机Chrome读取公网页面并截图。支持暂停和失败重试，已有预览与手动封面保留；失败不影响收藏。相关任务和检查报告不承诺重启续作。

### 数据、恢复与服务生命周期

正常 App 在 `~/Library/Application Support/DevResourceLibrary` 创建独立空库，SQLite、附件、配对信息与日志留在本机。App 拥有自己的标准库Python服务与独占库锁，验证对应实例；端口被占用时拒绝使用不相关服务，并显示重试和日志入口。关闭窗口后服务继续，扩展仍可采集；⌘Q / 退出拾集停止服务，重新打开恢复数据。

原网页库不自动迁移。带入旧数据须先从原库导出完整ZIP，再在App“管理资源 → 备份与恢复”选择文件，核对预检摘要并明确确认。JSON不携带附件；完整ZIP携带资源及附件字节。SQLite / JSON schema 3与ZIP manifest 2保持兼容，不改变正式库或原服务。

保留自动数据库快照与增量不可变附件对象、手动/每日完整ZIP、小时/日/周保留策略；恢复前先生成快照，摘要显示有效性与恢复范围。备份完整携带每个附件，存储复用不削减备份内容。

### 交付与验收范围

本候选目录已构建 `dist/Dev Resource Library.app`、App ZIP及`dist/shiji-browser-extension.zip`，App ZIP包含安装指南。App为本机ad-hoc签名构建，未公证、未上商店；扩展未发布到浏览器商店。完整安装、运行与迁移步骤见 `APP.md`；若当前运行临时QA App，先⌘Q退出，再从Finder正常启动以使用默认目录及8782端口。

本轮证据为180个Python测试、32个Node套件通过，ARM64 Swift构建通过，并实测原生搜索/收藏、配对面板及临时后端采集URL、选中文字与JPEG附件后自动出现在App。原生采集标签在深色图像与浅色画布上的对比证据约6.99:1 / 15.60:1；独立收尾验收为ship。测试仅用临时库；原生验收使用8783，服务测试使用临时端口，未触碰正式数据或8765服务。

浏览器安全策略禁止自动打开扩展管理页；没有绕过该限制，没有声称实际在Chrome/Edge安装后的端到端点击采集已通过。用户仍需按安装指南加载并配对。截图中的六条资源是合成QA内容，不是用户数据。

## Open Decisions

当前采用macOS + Chrome/Edge方案，Windows、Safari、Intel构建、云同步与多设备不在此次交付中。开发者证书公证、应用商店/扩展商店分发及实际Chrome/Edge安装后的点击验收尚未完成。浏览器仅使用CSS材质近似；管理区仍为混合应用，没有宣称完整原生重写。

## Product Principles

- 先保存，再整理；让真实内容和来源优先。
- 用户主动采集，本机保存，无账号、外部AI或跨设备云同步。
- 采集和自动刷新必须保留并发编辑与未保存草稿。
- 未知许可如实标注；封面不构成版权、授权或价格证据。
- 恢复先预检，已有数据先备份；新App保持独立库。
- 状态如实表达：加载、连接失败、禁用、恢复和完成各有明确反馈。
