# 拾集 iPhone

Chinese-speaking solo developer collects websites, design/audio/image inspiration and local materials, then finds them by topic or project. This surface is native iPhone browsing and capture, extending the existing desktop library and browser extension. It operates offline with a local App Group library shared with a system Share Extension. Minimum iOS17; native Liquid Glass on26+.

User request: “手机app也做一下”. User later prioritized phone–computer sync and confirmed same-Wi-Fi support. Independent local libraries remain offline-capable; an optional desktop HTTPS service, explicit pairing, guarded bidirectional resource/attachment exchange and optional phone foreground auto-sync connect them. No cloud account or signed-device-installation claim. Mobile app is a real native store, not a WebView for the desktop service. JSON3 and manifest2 remain unchanged. New source is isolated in work/mobile-app.

Success: share a URL/text/image into the library, browse clear large previews, edit notes and exact tags, recover a trashed item, confirm a backup import without overwriting current records, and synchronize both ways with explicit choices for concurrent or identity conflicts. A complex URL reuse that overlaps another stable phone record stops with accurate manual reconciliation guidance rather than guessing. The actual system Share Extension remains blocked by a persistent blank sheet and is not a verified success. Apple signing and matching App Group provisioning are prerequisites for physical installation. All shipped examples are absent; QA samples stay in a disposable simulator.
