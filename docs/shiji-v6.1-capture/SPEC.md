# V6.1 — Capture Everywhere

用户已授权按项目优化路线实施。当前阶段交付手机分享→电脑自动补全→手机回读，以及浏览器离线待发送／不确定结果恢复；之后再推进 Search & Scale、封面可控化和正式分发。

- 保留 V5 Hero、Spatial Deck、海报、Motion Studio / Calm、现有技术栈。
- SQLite schema 3、ZIP manifest 2、手机同步协议 1 不变。任务及发送回执是本机派生状态。
- 不操作正式资源库、服务或凭据；所有运行验收使用临时库、随机端口和一次性配对。
- 手机同步仅为新增或 URL 变化的非删除网站排队，不重新抓取全部历史收藏；同步后的人工内容优先。
- 扩展先持久保存冻结的采集内容，再发送。App 关闭或响应丢失时可恢复，不自动重复截取页面；待发送与已收藏明确区分。
- 配对变更不得把旧队列静默发送到另一资源库。取消待发送不意味着撤销可能已经完成的收藏。
- 功能分别提交；不推送、不合并 main。真机／真实安装缺少证据时明确标记未验收。
