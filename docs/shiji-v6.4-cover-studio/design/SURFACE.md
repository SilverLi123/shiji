Developer = actual code terminal / repository specimen / interface structure. Kinetic = echoed type / tension loops / rhythm sequence. Minimal = photo aperture / inset document / centered axis. Real images remain preferred; V5 remains explicitly selectable.

Editor / Operate: independent protected draft workspace; preview is central, style/layout left, appearance/text/image controls right. Narrow screen preview first. Existing control type/font/focus vocabulary; restrained neutral surfaces and primary save. No writes/uploads until Save; Cancel discards; Reset is explicit. Unknown future preferences are read-only except Reset. No decorative modal motion beyond existing owner.
