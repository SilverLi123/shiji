# Lab 美术方向记录 · 待用户确认

这是已实现评审表面的扫描记录，适用范围仅为 `docs/art-direction-lab/`。它不替换 `desktop-app/DESIGN.md`，也不形成获批产品令牌或新的自动生成规则。

## Overview

继承既有 **Creative Tech Dark · Motion Studio**：深色画廊承载收藏，荧光绿连接品牌与可执行控件。此轮集中检验真实资源能否拥有不同的主体、字体层级和留白，回应用户对“统一左标题／右形状”、SHIJI 灰色弱化和哈希决定美术的拒绝。

十二份保存的 QA 记录各有手工母版。折叠框、编辑器平面、等距舞台、组件标本、纸页、字带、真实图片、拓扑曲面、透明切片、文章、代码、Prompt 各自建立焦点。该手工编排只证明这十二份候选表达；语义匹配与任意资源生成尚未实现。

## Colors

画廊沿用深黑背景（`#0c0d10`）与荧光绿（`#d7ff65`）操作。Lab 正文和辅助文字由 `lab.css` 的局部变量负责，不能据此改写正式前景／次级文字令牌。SHIJI 用浅纸底与酸绿折叠框、暗色技术票据恢复力度；其他主体根据印刷、编辑器、场景或计算材料选择局部颜色。

AI 两张分别用暖色曲面与深蓝透明切片。颜色属于封面内容，不承担保存状态、类别正确性、授权或模型能力的证明。

## Typography

页面使用本机 `Avenir Next / Inter / Helvetica Neue / PingFang SC / sans-serif` 字族回退，没有远程字体加载。海报的大字随容器宽度缩放；印刷纸页使用 Georgia／宋体，代码使用系统等宽。Lab 的字体优先顺序是表面试验，不改变既有产品字族。

SHIJI 斜置大字，VS Code 跨越编辑器前缘，React Bits 使用字形标本，CSS transform 将变换作用于文字。Prompt 标题在“创作”之后明确换行，保留词语完整；真实正文位于纸页。完整资源标题始终在海报外再展示。代码保留七行缩进与标点，局部按固定行上色，不宣称新的通用词法分析器。

## Layout

页面最大宽（1500 px）；默认三列，1000 px 以下两列，620 px 以下单列。海报宽高比（1.22），容器圆角（14 px）；桌面板间距（34 × 22 px）。固定 390 px frame 用于移动网页评审，不移植原生界面。

共享尺寸、来源标注与外部资源标题使对照可读，内部主体位置逐张决定。对照复用同一实际保存记录，Poly Haven 两侧保留同一真实截图。旧版本只作为评审基线，不改造其算法或生产样式。

## Elevation & Depth

纸页、编辑器平面、折叠框和计算切片通过局部投影与色差描述材料；这些阴影属于美术主体。默认板静止；可选空间预览使用整体 CSS 透视和前景 `translate`，由 Lab 自己的控制器维护，不加载正式 Bits／Motion。

系统减少动态效果优先；指针采样合并到 requestAnimationFrame，后台与视图切换清理临时姿态。当前没有完整前景／主体／背景 Z 分层，也没有 V5 Spatial Deck。V3 球体与金属环的光照塑形仍比当前矢量表达更丰富；不将选择性研究描述为参考等效实现。

## Shapes

同一画廊圆角承载不同主体轮廓：SHIJI 为不规则折叠框和暗色斜票据，Godot 为等距块体，Motion Sites 为层叠圆盘与斜字带，AI 为曲面网格和透明平面，文字资源为折叠纸页。几何均是自绘研究，不能称为相关产品截图或品牌官方图形。

## Components

Lab 只有视图按钮、状态文字、海报板、对照与原始参考播放器。按钮以 `aria-pressed` 表达选中，键盘焦点可见；系统减少动态效果时空间开关禁用。读取失败由状态区域提示。

Poly Haven 图片来自既有本地预览，后续单张修正采用深绿底、倾斜奶油色照片纸与大字；CSS 仅裁取右侧建筑局部以避开网页导航与原有品牌标题，原图不变。这是针对已知图片的手工构图，不是通用裁图算法；代码和 Prompt 来自 Store 保存字段。SHIJI 的技术栈与标签为真实项目对应的手动 QA 输入。没有收藏按钮、模拟保存成功或 Lab 业务 localStorage；原始 Demo 的自有样例行为只留在隔离参考页。

## Do's and Don'ts

- Do 用真实保存字段与明确主体解释十二张设计，保留完整名称、来源和正文。
- Do 以原始参考、同资源对照和实际浏览器截图支撑评审，明确参考差距与测试边界。
- Do 将本文件保持为待确认的 Lab 方向，沿用正式产品世界与动效 owner。
- Don't 把手工样板宣称为已完成的语义生成引擎，或用哈希扩大模板组合替代美术指导。
- Don't 将抽象曲面／张量称为 AI 输出，或将网页照片与封面当作许可、价格、统计证据。
- Don't 在用户美术确认之前接入生产、改写既有 DESIGN／sidecar，或将本轮收尾评审视为用户接受。
